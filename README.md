# Codex Project Orchestrator

用于项目主控、子代理协作、进度持久化与跨对话交接的 Codex Skill。技能正文使用中文。

## 安装

将 `skills/project-orchestrator` 文件夹复制到 `~/.codex/skills/`（或自定义 `CODEX_HOME` 的 `skills/`）。在新会话中检查技能是否可用；具体发现行为以当前客户端为准。

## 使用

```text
使用 $project-orchestrator 接手当前项目，读取已有进度，核对工作区，按需分派子代理并持续更新检查点。
```

首次需要项目以后沿用时，可要求将协作规则合并到项目现有 `AGENTS.md`。技能不会在安装时自动修改项目，不附带后台服务或自动轮换程序。

## 交接方式

默认按里程碑保存检查点。用户授权且工具支持时，新建后继聊天并验证接管；否则生成可复制的启动提示词。精确 token 阈值自动轮换需要额外运行时支持，本仓库不将压缩或 Hook 描述成现成的自动交接功能。

技能不绑定个人主机、网络地址或具体仓库，也不依赖某个固定并发数。优先沿用项目现有任务与文档体系。

## 子代理与新聊天的区别

默认子代理协作中，主控仍留在原聊天，这是预期行为。子代理不等于侧栏中的独立聊天。若需要独立聊天，请明确指定模式，例如：

```text
使用 $project-orchestrator，采用独立聊天协作模式。
当前聊天只担任主控。我授权你在当前项目中创建执行聊天、读取进展，并向这些执行聊天发送后续任务。
先检查新建、读取/等待和消息工具是否可用；可用就实际创建并记录真实 ID，验收后继续调度。
若缺少能力，请明确说明并保存交接材料，不要静默改为原聊天包办。
本轮目标：[填写目标与验收标准]
```

此提示词不能让原本不可用的工具变得可用。独立聊天的创建、观察和继续执行取决于当前客户端和会话能力。技能不保证按精确 token 阈值自动换聊天。
